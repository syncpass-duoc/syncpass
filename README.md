# SyncPass

## Integrantes

- Ignacio Flores
- Renato Fuentes

## Caso

SyncPass es una aplicacion Android para consultar eventos, crear eventos y tomar asistencia mediante la lectura de codigos QR, pensada para optimizar la toma de asistencia y tener un mejor feedback de eventos como cursos en unidades vecinales, etc.

Esta desarrollada en Kotlin con Jetpack Compose y guarda los usuarios y eventos localmente con Room.

## Funcionalidades Implementadas

- Registro e inicio de sesion de docentes, estudiantes y asistentes.
- Lista de eventos con fecha, lugar, inscritos y cupos.
- Lectura de códigos QR mediante el uso de la camara.
- Navegacion entre Eventos, Escaner y Pendientes

## Como ejecutar el proyecto

1. Abre la carpeta del proyecto en un IDE como Android Studio.
2. Espera que termine la sincronizacion de Gradle.
3. Inicia un emulador o conecta un dispositivo con Android 8.0 o superior.
4. Selecciona la configuracion 'app' y pulsa **run**
5. Registra un usuario para iniciar sesion y prueba las funcionalidades disponibles!
